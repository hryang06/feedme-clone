# spec.md — URL to Markdown 변환기

## 개요

웹 페이지 URL을 붙여넣으면 본문을 Markdown으로 변환해 보여주는 단일 페이지 도구.
사용자는 결과를 복사하거나 파일로 내려받고, 프롬프트를 앞에 붙여 AI 서비스에 바로 보낼 수 있다.

---

## 범위

### 포함
- URL 입력 + 수동 변환 트리거
- 변환 결과 표시 (제목·저자 헤더 + 렌더링된 Markdown)
- 내보내기: Markdown 복사 / .md 파일 다운로드 / AI용 복사 (프롬프트+Markdown 클립보드)
- 프롬프트 프리셋 3종 (요약해줘 / 한국어로 번역해줘 / 쉽게 설명해줘) + 직접 입력 (세션 유지)
- 입력 초기화 (지우기 버튼)
- 다크모드 토글
- 오류 처리 (잘못된 URL 형식 / 페이지 로드 실패 / 본문 추출 실패)

### 제외
- 로그인·계정 — 인증이 필요한 페이지 지원을 단순화하기 위해 제외. 추후 확장 가능
- 변환 이력 저장 — MVP 범위 외; 세션이 끝나면 결과 사라짐
- 프롬프트 프리셋 커스터마이징·저장 — 1회용 직접 입력으로 충분; 저장은 추후
- ChatGPT / Claude 별도 분기 — 복사 내용이 동일하므로 단일 "AI용 복사" 버튼으로 통합

---

## 시나리오

### 1. 유효한 URL 변환 (happy path)

- **Given** — URL 입력창이 비어 있는 초기 화면
- **When** — 유효한 URL을 입력창에 붙여넣고 "변환" 버튼 클릭
- **Then** — 로딩 인디케이터가 나타났다가 사라지고, 결과 영역에 페이지 제목·저자 헤더와 렌더링된 Markdown이 표시된다

성공 기준:
- [ ] 유효한 URL 입력 → "변환" 버튼이 활성화된다
- [ ] "변환" 버튼 클릭 → 로딩 인디케이터가 표시된다
- [ ] 변환 완료 → 로딩 인디케이터가 사라지고 결과 영역이 나타난다
- [ ] 결과 영역에 추출된 페이지 제목이 표시된다
- [ ] 결과 영역에 추출된 저자 이름이 표시된다
- [ ] 결과 영역에 Markdown이 렌더링되어 표시된다 (헤딩, 단락, 링크 등 기본 마크다운 요소 포함)

---

### 2. 입력 초기화

- **Given** — URL이 입력된 상태 (변환 전 또는 후)
- **When** — 지우기 버튼 클릭
- **Then** — URL 입력창이 빈 상태로 돌아가고, 결과 영역이 사라진다

성공 기준:
- [ ] 지우기 버튼 클릭 → 입력창이 비어 있다
- [ ] 지우기 버튼 클릭 → 결과 영역이 화면에서 사라진다

---

### 3. Markdown 복사

- **Given** — 변환 결과가 표시된 상태
- **When** — "복사" 버튼 클릭
- **Then** — Markdown 원문이 클립보드에 복사되고, 버튼이 복사 완료 상태(예: "복사됨")로 잠시 변경된다

성공 기준:
- [ ] "복사" 버튼 클릭 → 버튼 라벨이 완료 상태 텍스트로 변경된다
- [ ] 완료 상태 텍스트는 수초 후 원래 라벨로 돌아온다

---

### 4. .md 파일 다운로드

- **Given** — 변환 결과가 표시된 상태
- **When** — "다운로드" 버튼 클릭
- **Then** — `.md` 확장자 파일이 브라우저 기본 다운로드 경로에 저장된다

성공 기준:
- [ ] "다운로드" 버튼 클릭 → `.md` 확장자 파일이 다운로드된다
- [ ] 다운로드된 파일의 내용은 결과 영역에 표시된 Markdown과 동일하다

---

### 5. AI용 복사 — 프롬프트 없음

- **Given** — 변환 결과가 표시된 상태
- **When** — "AI에 보내기" 버튼 클릭 → 프롬프트 선택 없이 "AI용 복사" 버튼 클릭
- **Then** — Markdown 본문만 클립보드에 복사된다

성공 기준:
- [ ] "AI에 보내기" 버튼 클릭 → 프롬프트 선택 UI가 노출된다
- [ ] 프롬프트를 선택하지 않은 상태에서 "AI용 복사" 클릭 → 복사 완료 상태가 표시된다

---

### 6. AI용 복사 — 프리셋 프롬프트 선택

- **Given** — "AI에 보내기" 클릭으로 프롬프트 선택 UI가 열린 상태
- **When** — 프리셋 3개(요약해줘 / 한국어로 번역해줘 / 쉽게 설명해줘) 중 하나를 선택하고 "AI용 복사" 클릭
- **Then** — `[선택한 프롬프트]\n\n[Markdown]` 형식으로 클립보드에 복사된다

성공 기준:
- [ ] 프롬프트 선택 UI에 프리셋 3개가 모두 표시된다
- [ ] 프리셋 선택 후 "AI용 복사" 클릭 → 복사 완료 상태가 표시된다

---

### 7. AI용 복사 — 직접 입력 프롬프트

- **Given** — "AI에 보내기" 클릭으로 프롬프트 선택 UI가 열린 상태
- **When** — "직접 입력" 선택 → 텍스트 입력창에 프롬프트를 작성하고 "AI용 복사" 클릭
- **Then** — `[입력한 프롬프트]\n\n[Markdown]` 형식으로 클립보드에 복사된다

성공 기준:
- [ ] "직접 입력" 선택 → 텍스트 입력창이 노출된다
- [ ] 입력창에 텍스트 작성 후 "AI용 복사" 클릭 → 복사 완료 상태가 표시된다
- [ ] 페이지를 새로고침하면 직접 입력한 프롬프트 내용이 초기화된다
- [ ] 새 URL로 변환해도 직접 입력한 프롬프트 내용은 유지된다

---

### 8. 잘못된 URL 형식 입력

- **Given** — URL 입력창이 비어 있는 초기 화면
- **When** — URL 형식이 아닌 텍스트(예: `not-a-url`)를 입력하고 "변환" 버튼 클릭
- **Then** — 입력창 아래에 인라인 에러 메시지가 표시된다. 결과 영역은 나타나지 않는다

성공 기준:
- [ ] URL 형식이 아닌 값 입력 후 "변환" 클릭 → 입력창 아래 에러 메시지가 표시된다
- [ ] 에러 메시지가 표시된 상태에서 입력창을 수정하면 에러 메시지가 사라진다

---

### 9. 페이지 로드 실패

- **Given** — 유효한 URL 형식이지만 존재하지 않거나 타임아웃되는 주소를 입력한 상태
- **When** — "변환" 버튼 클릭
- **Then** — 로딩 인디케이터가 나타났다가 사라지고, 결과 영역에 페이지 로드 실패 에러 메시지가 표시된다

성공 기준:
- [ ] 응답 없는 URL 변환 시도 → 결과 영역에 에러 메시지가 표시된다
- [ ] 에러 메시지 표시 후에도 입력창에 URL이 유지되어 사용자가 수정할 수 있다

---

### 10. 본문 추출 실패

- **Given** — 페이지는 로드되지만 본문 추출이 불가능한 URL(예: 로그인 전용, JS 전용 SPA) 입력
- **When** — "변환" 버튼 클릭
- **Then** — 결과 영역에 본문 추출 실패 에러 메시지가 표시된다

성공 기준:
- [ ] 본문 추출 불가 페이지 변환 → 결과 영역에 에러 메시지가 표시된다

---

### 11. 제목이 없는 페이지

- **Given** — 제목 메타데이터가 없는 페이지 URL을 변환한 결과가 표시된 상태
- **Then** — 결과 헤더에 페이지 URL의 도메인(예: `medium.com`)이 제목 대신 표시된다

성공 기준:
- [ ] 제목 없는 페이지 변환 → 결과 헤더에 도메인 이름이 표시된다

---

### 12. 저자 정보가 없는 페이지

- **Given** — 저자 메타데이터가 없는 페이지 URL을 변환한 결과가 표시된 상태
- **Then** — 결과 헤더에서 저자 행이 표시되지 않는다 (빈 값 대신 행 자체가 숨겨짐)

성공 기준:
- [ ] 저자 없는 페이지 변환 → 결과 헤더에 저자 행이 존재하지 않는다

---

### 13. 다크모드 토글

- **Given** — 라이트 모드 상태의 화면
- **When** — 다크모드 토글 클릭
- **Then** — 화면 전체가 다크 테마로 전환된다. 다시 클릭하면 라이트 테마로 돌아온다

성공 기준:
- [ ] 다크모드 토글 클릭 → `html` 요소에 다크 테마 클래스가 적용된다
- [ ] 다크모드 상태에서 토글 재클릭 → 라이트 테마 클래스로 복원된다

---

## 불변 규칙

**데이터 일관성**: 복사 및 다운로드로 내보내는 내용은 결과 영역에 표시된 Markdown과 항상 동일해야 한다. 내보내기 시점에 변환을 다시 수행하지 않는다.
